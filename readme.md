# 🍽️ Restaurant Ordering System

A full-stack **Restaurant Ordering System** built with **PHP and MySQL**. The system provides a complete workflow for customers, restaurant staff, and administrators.

The project was developed as a practical web application to improve my skills in **PHP, MySQL, authentication, database management, CRUD operations, order processing, and dashboard development**.

---

## 🚀 Project Overview

The Restaurant Ordering System allows customers to browse food items, add products to their cart, place orders, manage their profiles, and view previous orders.

The system also includes dedicated **Admin** and **Staff** panels for managing restaurant operations.

## 🛒 Ordering System

The main ordering workflow is:

```text
Customer
   ↓
Browse Menu
   ↓
Select Food
   ↓
Add to Cart
   ↓
Review Cart
   ↓
Checkout
   ↓
Place Order
   ↓
Order Processing
   ↓
Order Details
```

## 🔐 User Roles

The system is designed around three main roles:

| Role        | Main Responsibilities                                       |
| ----------- | ----------------------------------------------------------- |
| 👤 Customer | Browse food, cart, checkout, orders, wishlist               |
| 👨‍🍳 Staff | Manage food, offers, and restaurant orders                  |
| 👨‍💼 Admin | Manage users, staff, menu, categories, orders, and settings |
